# OW 中継 VPN（利用者向け）

オーバーウォッチの通信だけを中継サーバー経由にして、**回線や経路の相性による切断・ラグを回避する** ための VPN です。
管理者が **承認した PC だけ** が使えます。

> 非公式の個人運営ツールです。Blizzard Entertainment とは関係ありません。

## 特徴

- **OW の通信だけ** が VPN を通ります。Web・動画・配信・ほかのゲームには影響しません
- 一度セットアップすれば、**PC を起動するだけで自動でつながります**
- 鍵はあなたの PC の中で作られ、外には出ません。配布用の zip をほかの人が手に入れても、管理者が承認しない限り使えません

## 必要なもの

- Windows 10 / 11
- **[`ow-vpn-kit.zip` をダウンロード](https://github.com/TAKUMIN29/ow-vpn-client/releases/latest/download/ow-vpn-kit.zip)**（[Releases](https://github.com/TAKUMIN29/ow-vpn-client/releases)）
- インストール中に 1 回だけ管理者権限（「はい」を押すだけ）

## はじめかた（1 回だけ）

1. 上のリンクから `ow-vpn-kit.zip` をダウンロードし、好きな場所に展開する（デスクトップなど）
2. **`セットアップ.bat`** をダブルクリック
   - 「このアプリがデバイスに変更を加えることを許可しますか？」→ **はい**
   - 「Windows によって PC が保護されました」と出たら → **詳細情報** → **実行**
   - VPN ソフト（[WireGuard](https://www.wireguard.com/) 公式版）が入っていなければ自動でインストールされます
3. 画面に出る **申請コード** を管理者に送る（1on1で送ってください）
   - 自動でコピーされています。同じフォルダの `申請コード.txt` にも保存されます
4. 管理者（オーナー）が承認すると **自動でつながります**（あなたの操作は不要）
   - 確かめるときは **`状態確認.bat`** →「接続 OK」ならそのまま OW を起動

## 2 回目以降

**何もしなくて OK** です。PC を起動すると自動でつながります。

| こんなとき | やること | 再申請 |
|---|---|---|
| PC の再起動 | 何もしない | 不要 |
| `セットアップ.bat` をもう一度実行 | ─ | 不要（同じ申請コードのまま） |
| `削除.bat` を実行した | `セットアップ.bat` → 申請コードを送る | **必要** |
| PC の買い替え・Windows の再インストール | `セットアップ.bat` → 申請コードを送る | **必要** |

## バッチの説明

| ファイル | 内容 |
|---|---|
| `状態確認.bat` | つながっているか確認（申請コードも再表示） |
| `停止.bat` | VPN を切る。自動接続も止まる（OW がつながらないとき等） |
| `再開.bat` | もう一度つなぐ。自動接続にも戻る |
| `削除.bat` | VPN をこの PC から消す（WireGuard 本体を消すかも聞かれます）。もう一度使うには再申請が必要 |

- **「承認待ち」のまま** → 申請コードが管理者に届いているか確認してください
- **「接続を確認できません」** → インターネット接続を確認し、`停止.bat` → `再開.bat` を試してください。直らなければ管理者へ
- **市販の VPN と同時に使う** と、うまく動かないことがあります

## OW で VPN 経由になっているか確かめる

PowerShell で次を実行し、`ow-vpn` と表示されれば VPN 経由です（ゲームサーバーの IP の一例で確認）。

```powershell
Find-NetRoute -RemoteIPAddress 34.146.235.76 | Select-Object -First 1 InterfaceAlias
```

## プライバシー

| 項目 | 内容 |
|---|---|
| あなたの PC に保存されるもの | この PC 専用の鍵と接続設定（`C:\ProgramData\OW-VPN`、管理者権限でのみ読み取り可） |
| 管理者に見えるもの | 最後に接続した時刻、接続元の IP アドレス、VPN を通った通信量。中継サーバーを通るため、OW の通信の宛先（ゲームサーバー）やパケットの大きさも技術的には見ることができます |
| 管理者に見えないもの | OW 以外の通信（Web・動画・ほかのアプリなど。そもそも VPN を通りません） |
